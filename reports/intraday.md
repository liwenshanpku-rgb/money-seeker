# 小时线动量（日内 / 超短线）

数据：Coinbase BTC-USD 小时线，2016-01 至 2026-10-22（94,690 根，21 处小缺口用前值填充）。
样本内 2016–2021 选参，样本外 2022-01 至今检验。复现：

```bash
python -m money_seeker intraday            # 下载数据并回测；或 --csv 指定已下载的小时线
```

完整结果：[`intraday_grid.csv`](intraday_grid.csv)（124 个组合 × 5 档成本）。

## 测了什么

| 类别 | 规则 | 参数 |
|---|---|---|
| 时间序列动量 `tsmom` | 过去 n 小时涨就持有，跌就空仓（或做空） | n = 1, 2, 3, 6, 12, 24, 48, 72, 168 |
| 均线交叉 `ema` | 快线在慢线上方持有 | 快 3–24 小时，慢 24–168 小时 |
| 突破 `breakout` | 突破过去 n 小时最高价买入，跌破过去 n/2 小时最低价离场 | n = 6–168 |
| 日内动量 `daymom` | UTC 当天 0 点到 h 点上涨，就持有到当天收盘 | h = 6–22 |

每种都测"只做多 / 空仓"（现货）和"多空双向"（永续合约，未计资金费率）。
单边成本 5 档：0、0.05%（永续 / 高等级挂单）、0.10%、0.25%（Kraken 入门挂单）、0.40%（Kraken 入门吃单）。

## 结果

样本外（2022 至今）买入持有：年化 11.7%，夏普 0.47，最大回撤 −67%。

| 单边成本 | 样本内最优 | 样本外年化 | 夏普 | 样本外跑赢买入持有的组合占比 |
|---|---|---|---|---|
| 0 | daymom(12) | 3.5% | 0.26 | 25% |
| 0.05% | breakout(168) | 19.6% | 0.77 | 4% |
| 0.10% | breakout(168) | 17.0% | 0.69 | 1% |
| 0.25% | breakout(168) | 9.3% | 0.45 | 0% |
| 0.40% | breakout(168) | 2.1% | 0.22 | 0% |

1. **真正的日内规则全部被成本吃掉。** 1 小时动量没有成本时就是负收益；交易边际（每次一进一出平均赚多少，未扣成本）只有 4–14 个基点，而 Kraken 入门费率一进一出就要 50–80 个基点。
2. **有一个真实但做不了的效应：** 尾盘动量 daymom(22)（UTC 0–22 点上涨就持有最后 2 小时）在样本内外都成立（样本外夏普 1.08，安慰剂 p = 0.025），但每次只赚约 5.5 个基点，单边成本 0.05% 时年化就变成 −8%。
3. **唯一扣完成本还能活下来的是 breakout(168)：** 7 天突破，每年约 22 次交易，每次赚约 106 个基点。它其实是**多日趋势**，不是日内。成本 0.25% 时：
   - 年化 9.3%，低于买入持有的 11.7%，但最大回撤只有 −36%（买入持有 −67%）；
   - 安慰剂 p = 0.06，勉强显著；
   - 晚一小时成交不影响结果。
4. **税：** 收益全是短期利得。按 45% 粗算，breakout(168) 税后年化只剩约 4.3%。买入持有不卖就不交税；方案 B 2022 年以来共调仓 14 次（每年约 3 次），每次只动一半仓位。
5. **对照：** 方案 B（200 日均线）2022 年起年化 20.2%、最大回撤 −40%（见 [`btc.md`](btc.md)），收益是 breakout(168) 的两倍多，交易次数只有它的七分之一。

### breakout(168)，成本 0.25%，分年收益

| 年 | 策略 | 买入持有 |
|---|---|---|
| 2022 | −24.0% | −64.6% |
| 2023 | +38.1% | +155.8% |
| 2024 | +70.3% | +120.8% |
| 2025 | −13.9% | −6.3% |
| 2026 年初至今 | −0.4% | −7.2% |

## 结论

不建议做日内动量。小时级别的动量在 BTC 上确实存在，但幅度比散户的交易成本小一个数量级；能扣完成本活下来的只有多日趋势，而这一点方案 B 已经用更低的频率和更低的税做到了。
