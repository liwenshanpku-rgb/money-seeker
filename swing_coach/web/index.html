    方式二：自动点评 需要配置 GitHub 和 Claude token，结果自动显示在本页

    把 10 张关键帧和测量数据推送到 GitHub 仓库的 swing-coach 分支，由 GitHub Actions 里的 Claude Code 写出点评（用订阅额度），通常 2–5 分钟。可以先关掉页面，稍后回来点「查看上次点评」。

    GitHub 设置（只需一次）

    在 GitHub → Settings → Developer settings → Fine-grained tokens 新建，只选这个仓库，权限 Contents 选 Read and write。token 只保存在这台设备的浏览器里。

    拍摄建议

    • 正面（Face-on）：相机正对胸口，高度约在腰部，球员居中；适合看重心转移、头部稳定、侧倾、手领先。
    • 侧面（Down-the-line）：相机在球员身后、沿目标线方向，镜头对准双手；适合看脊柱角、提前伸展、挥杆平面。
    • 相机固定（三脚架），全身和球杆都在画面里，光线充足，穿与背景对比明显的衣服。
    • 手机用「慢动作」或 60/120fps 拍摄效果最好；一段视频只包含一次挥杆。
    • 测量来自 2D 视频，存在透视误差，请关注趋势和明显偏差，细微数值差异不必在意。
    姿态识别：MediaPipe Pose（在浏览器本地运行）。职业模板为 P1–P10 位置的典型职业参数，不代表某位具体球员。
